# YuvaIntern Week 4 – Statistical Analysis and Hypothesis Testing

## Project Overview
This project focuses on statistical analysis and hypothesis testing using the Online Retail dataset. The objective is to validate business insights using statistical techniques and interpret the results with Python.

## Objectives
- Perform statistical analysis on retail transaction data.
- Formulate null and alternative hypotheses.
- Apply statistical tests and interpret p-values.
- Examine relationships between sales variables.
- Understand statistical assumptions, confidence intervals, effect sizes, and limitations.

## Tools and Technologies
- Python
- Pandas and NumPy
- SciPy
- Statsmodels
- Matplotlib and Seaborn
- Jupyter Notebook / VS Code

## Statistical Techniques
1. **Welch’s t-test:** Compare average daily revenue between January and February 2011.
2. **Pearson Correlation:** Examine the relationship between quantity and revenue.
3. **Chi-square Test:** Investigate the association between month and cancellation status.
4. **OLS Regression:** Explore the statistical relationship between quantity, unit price, and revenue.

## Dataset
The project uses the Online Retail dataset, which contains retail transaction information such as invoice numbers, product descriptions, quantities, invoice dates, unit prices, customer IDs, and countries.

## Project Workflow
1. Load and inspect the dataset.
2. Check missing values and duplicate records.
3. Prepare data and calculate revenue.
4. Formulate hypotheses for statistical testing.
5. Apply statistical tests using SciPy and Statsmodels.
6. Evaluate p-values using a significance level of 0.05.
7. Interpret the results while considering assumptions and limitations.
8. Document the findings in a statistical analysis report.

## Key Learning Outcomes
- Understanding hypothesis testing and statistical significance.
- Interpreting p-values and confidence intervals.
- Measuring correlation between variables.
- Applying Chi-square tests and regression analysis.
- Communicating statistical findings responsibly.

## Project Files
- `Week4_Statistical_Analysis.ipynb` – Python analysis and statistical tests.
- `YuvaIntern_Week4_Statistical_Analysis_Report.docx` – Detailed project report.
- `Week4_Statistical_Test_Summary.csv` – Summary of statistical test results.
- `Charts/` – Relevant visualizations, if included.

## Important Notes
Statistical significance does not necessarily imply practical importance or causation. Revenue is calculated as quantity multiplied by unit price, so its relationship with these variables is partly mathematical. Results should be interpreted alongside test assumptions and dataset limitations.
